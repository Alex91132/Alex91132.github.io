# alex91132.github.io

Сайт-портфолио Александра Федорова, руководителя проектов и аналитика данных: **[alex91132.github.io](https://alex91132.github.io/)**.

На сайте — опыт, проекты с карточками и ссылками на код и отчёты, резюме в PDF и блог.

Статический сайт без сборки: чистые HTML и CSS, публикуется GitHub Pages из корня ветки `main`.

| Файл | Что |
|---|---|
| `index.html` | главная: о себе, опыт, проекты, навыки, обучение, свежие записи блога |
| `blog.html`, `posts/` | блог и статьи |
| `styles.css` | стили всех страниц |
| `assets/` | фото, иконка, картинка для превью в соцсетях, резюме, картинки карточек проектов (`assets/projects/`) |
| `404.html` | страница «не найдено» — GitHub Pages отдаёт её автоматически |
| `robots.txt`, `sitemap.xml` | индексация: карта сайта со всеми страницами проектов |

Посмотреть локально:

```bash
python -m http.server 8000
```

и открыть http://localhost:8000.

Две карточки — «Симулятор A/B-тестов» и «Ковёр бурения» — ссылаются на `/ab-simulator/` и
`/drilling-carpet/`: эти страницы живут в отдельных репозиториях и обслуживаются их
собственными GitHub Pages, поэтому в локальном превью они не откроются. Так сделано
намеренно, чтобы адреса демо не менялись.

Код проектов — в репозиториях [github.com/Alex91132](https://github.com/Alex91132).
