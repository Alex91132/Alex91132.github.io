# alex91132.github.io

Сайт-портфолио Александра Федорова, аналитика данных: **[alex91132.github.io](https://alex91132.github.io/)**.

На сайте — опыт, проекты с карточками и ссылками на код и отчёты, резюме в PDF и блог.

Статический сайт без сборки: чистые HTML и CSS, публикуется GitHub Pages из корня ветки `main`.

| Файл | Что |
|---|---|
| `index.html` | главная: о себе, опыт, проекты, навыки, обучение, свежие записи блога |
| `blog.html`, `posts/` | блог и статьи |
| `styles.css` | стили всех страниц |
| `assets/` | фото, иконка, картинка для превью в соцсетях, резюме, картинки карточек проектов (`assets/projects/`) |

Посмотреть локально:

```bash
python -m http.server 8000
```

и открыть http://localhost:8000.

Код проектов — в репозиториях [github.com/Alex91132](https://github.com/Alex91132).
